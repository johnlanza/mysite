# Royal Podcast Society opening music

`rps-mouret-rondeau-opening.mp3` is a new, brief performance created for the
Royal Podcast Society from the public-domain melody of Jean-Joseph Mouret's
*Rondeau* from *Premiere Suite de Symphonies* (1729).

It does not contain audio from the PBS *Masterpiece Theatre* recording or any
other third-party recording.
